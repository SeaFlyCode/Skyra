## Knowledge base

Ce projet maintient une base de connaissance dans `.claude/knowledge/`.

- **Avant d'agir** sur deploy/release/archi, consulter le `.md` correspondant.
- **Après un fix** → ajouter une entrée dans `incidents.md`.
- **Après une tâche faite** → mettre à jour `roadmap.md`.
- **Si procédure change** → mettre à jour `deploy.md` / `release-*.md`.
- **Si nouveau composant** → mettre à jour `architecture.md`.

Voir skill `knowledge-base` pour le détail.
